# Mi mundo marino

Pantalla de bienvenida para Android (Java) con tema de mar y velero.

- **Idiomas:** español (por defecto), inglés, italiano, portugués y alemán.
- **Tamaños y orientación:** `layout` vertical (título arriba, barco abajo) y `layout-land` horizontal (texto a la izquierda, barco a la derecha). Medidas distintas para teléfono, tablet de 7" y tablet de 10" / TV.
- **Fondo nine-patch:** `drawable-nodpi/fondo_marino.9.png` (cielo, sol y mar que se estiran sin deformarse).

## Cómo abrirlo
Abre la carpeta en Android Studio (*File > Open*), espera a que Gradle sincronice y ejecuta en un emulador.
